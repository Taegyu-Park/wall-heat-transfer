# 벽체 열전달 시뮬레이터

다층 벽체의 **열저항·온도 분포·축열에 의한 시간지연**을 직접 조절하며 이해하는 교육용 웹 도구입니다.
건축환경조절시스템 「02. Thermal Energy and Heat Transfer」 강의 내용(전도·대류·복사, 직렬·병렬 열저항)을 바탕으로 만들었습니다.

**바로 사용하기:** https://taegyu-park.github.io/wall-heat-transfer/

## 기능

| 탭 | 내용 | 강의 범위 |
|---|---|---|
| 원리 설명 | 열전달 세 방식: 푸리에 법칙(식·변수 설명, 현재 벽 값으로 직접 계산), 뉴턴 냉각법칙, 슈테판–볼츠만 법칙, 표면 대류+복사 병렬, 상당외기온도 | 18–29p, 39–40p |
| ① 정상상태 · 직렬 | 층별 R = L/k 와 온도 기울기, R_total, U, q, 벽 속 온도 분포, 열저항 회로 막대, 표면 열수지(대류·복사·일사) | 18–29p (푸리에 법칙, 직렬 저항, 층 사이 온도) / 39–40p (표면 열전달) |
| ② 하루 변화 · 축열 | 외기가 하루 주기로 변할 때 벽 속 온도 애니메이션, 감쇠계수·시간지연, **현재 벽과 층 순서를 뒤집은 벽 비교** (내단열 ↔ 외단열) | 24p (정상상태 가정의 한계) |
| ③ 병렬 · 열교 | 열교 면적 비율에 따른 평균 U, 면적 비중 대비 열손실 비중 | 25p (병렬 구성) |

- 재료 프리셋: 콘크리트, EPS·XPS 단열재, 미네랄울, 벽돌, 목재, 석고보드, 모르타르, 강재 (k, ρ, c 직접 수정 가능, 층별·전체 **↺ 기본값** 버튼으로 일반값 복원)
- 표면 경계 조건: 대류 h_c, 장파 복사(방사율 ε), 일사(일사량 I, 흡수율 α)
- 예제: 강의 29p 예제 (40℃ / 10℃, 세 층) 를 기본으로 불러와 손계산과 비교할 수 있음

## 계산 방법

- **정상상태:** `q = (T_out − T_in) / ΣR`, 각 층 `ΔT_i = q·R_i`
- **표면 열전달:** 대류와 복사가 병렬 → `R_s = 1/(h_c + h_r)`. 복사계수 `h_r = εσ(T_s² + T_r²)(T_s + T_r)` 는 표면온도에 따라 달라지므로 반복 계산해 비선형 `εσ(T_s⁴ − T_r⁴)` 를 정확히 만족시킵니다 (주위 면 온도 = 같은 쪽 공기온도 가정). 기본값 h_c 실외 20 / 실내 2.5, ε = 0.9 → R_se ≈ 0.04, R_si ≈ 0.13 (ISO 6946 수준).
- **일사:** 상당외기온도 `T_sa = T_out + αI/h_o` 로 바꿔 `q = (T_sa − T_in)/ΣR`.
- **비정상(②탭):** 벽을 약 5 mm 유한체적 격자로 나누고, 선형 열전도 방정식을 평균 성분(ω = 0)과 하루 주기 성분(ω = 2π/24h)으로 나누어 주파수 영역에서 풉니다(복소 삼중대각 해법). 그래서 예열 계산 없이 **매일 반복되는 주기 정상상태**를 바로 얻습니다. 실내 공기온도는 일정하다고 가정합니다. 표면 h(대류+복사)는 일평균 외기 조건에서 구해 고정하며, 일사는 포함하지 않습니다.
  - 감쇠계수 f = 실내 열류 진폭 ÷ 정상상태 가정 시 진폭 (ISO 13786의 decrement factor와 같은 개념)
  - 시간지연 = 외기 최고 시각 → 실내 열류 최고 시각
- **병렬(③탭):** `U_avg = (1 − f)·U_A + f·U_B`. 열교는 R이 가장 큰 층을 관통해 그 층의 k를 대체한다고 가정한 1차원 근사입니다.

## 실행 / 개발

빌드 과정과 의존성이 없는 정적 사이트입니다. ES 모듈을 쓰기 때문에 로컬에서는 간단한 서버로 열어야 합니다.

```bash
python -m http.server 8000   # → http://localhost:8000
npm test                     # 물리 계산 단위 테스트 (Node 18+)
```

```
index.html, style.css
js/physics.js   계산 모듈 (DOM 의존성 없음, 테스트 대상)
js/plot.js      SVG 그래프 도우미
js/app.js       UI 상태·렌더링
tests/          node:test 단위 테스트 (강의 예제 손계산, 정상/비정상 일관성, 격자 수렴, 복사·일사 열수지 등)
```

`main` 브랜치에 push하면 GitHub Actions가 테스트를 실행한 뒤 GitHub Pages로 배포합니다.
